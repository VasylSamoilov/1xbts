# Contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md) before making changes. Follow its scope,
validation, and pull request guidance.

- Match existing code style and crate boundaries. Keep changes focused.
- Use `--release` for Rust builds, tests, runs, and Clippy. Run formatting and
  relevant tests, and report any checks you could not run.
- Update `CHANGELOG.md` under `# HEAD` for user-visible changes. Keep entries brief.
- Do not add agent attribution or co-author trailers to commits or PR descriptions.
- Keep credentials, build output, logs, and large captures out of commits.
